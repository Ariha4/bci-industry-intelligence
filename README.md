# BCI Industry Intelligence Dashboard

An interactive market-intelligence tool for the brain-computer interface (BCI) space, built on public clinical trial data. It answers the kind of questions a BCI strategy/market-intelligence team needs on an ongoing basis: is trial activity growing, which patient populations are being targeted, who are the competitive sponsors, how mature is each company's pipeline, and where is trial volume outpacing sponsor coverage (a signal for underserved patient need).

**Live pipeline, not a static scrape.** The dataset is pulled fresh from the [ClinicalTrials.gov API v2](https://clinicaltrials.gov/data-api/api) every time the pipeline runs, and a scheduled [GitHub Actions workflow](.github/workflows/refresh-data.yml) refreshes it automatically every week, so the dashboard always reflects current trial activity rather than a snapshot.

## What it shows

- **Trial volume over time** — overall, and broken out by the patient populations BCIs primarily target (ALS, spinal cord injury, stroke, epilepsy, locked-in syndrome)
- **Sponsor / competitive landscape** — trial counts by lead sponsor, colored by sponsor type (industry vs. academic/NIH), covering the named BCI competitive set (Blackrock Neurotech, Neuralink, Synchron, Precision Neuroscience, Paradromics, Onward Medical, and others)
- **Trial phase funnel** — a rough proxy for how far each part of the field has progressed toward approval
- **Regulatory cross-reference** — active trial sponsors matched against known FDA Breakthrough Device Designation status (hand-compiled and cited, since the FDA does not expose a queryable API for this program — see [`data/reference/fda_breakthrough_devices.csv`](data/reference/fda_breakthrough_devices.csv))
- **"White space" signal** — conditions with real recent trial activity but very few distinct sponsors, as a simple heuristic for validated patient need with thin competitive coverage

## Why these queries, not a single keyword search

A naive full-text search for "brain-computer interface" is too noisy — it also matches unrelated trials that happen to contain the word "interface" (referral-process studies, mental-health care coordination) or "brain" (unrelated CNS oncology trials). The pipeline instead runs targeted queries against specific API fields — device intervention names, named sponsors, and condition-plus-device-type combinations — and merges the results, de-duplicated by NCT ID. See the module docstring in [`src/fetch_trials.py`](src/fetch_trials.py) for the full query strategy.

## Project structure

```
src/
  fetch_trials.py   # ETL: pulls raw trial records from ClinicalTrials.gov API v2
  process.py        # Flattens nested API JSON into a tidy DataFrame
  analyze.py         # Trend, sponsor-landscape, phase-funnel, regulatory, white-space logic
app.py               # Streamlit dashboard
data/reference/      # Hand-compiled, cited reference data (FDA designations)
data/raw/            # Generated by the pipeline — not committed except the tidy CSV
tests/               # pytest suite, run against fixture data (no network needed)
.github/workflows/   # Scheduled data refresh via GitHub Actions
```

## Running it locally

```bash
pip install -r requirements.txt

python src/fetch_trials.py    # pulls live data from ClinicalTrials.gov (~2-3 min)
python src/process.py         # flattens into data/raw/trials_processed.csv

streamlit run app.py
```

## Running the tests

```bash
python -m pytest tests/ -v
```

Tests run entirely against local fixture data (`tests/fixtures/sample_studies.json`) — no network access required, so they run the same way in CI as they do locally.

## Data sources & limitations

- Trial data: [ClinicalTrials.gov API v2](https://clinicaltrials.gov/data-api/api), public and free, no authentication required.
- FDA Breakthrough Device Designation status: hand-compiled from public reporting (the FDA does not publish a queryable database for this program). Sourced and cited in `data/reference/fda_breakthrough_devices.csv` — treat as directionally accurate rather than a legal record, and a couple of designation years reflect the best publicly available reporting at time of writing rather than an official FDA-confirmed date.
- Sponsor names on ClinicalTrials.gov aren't always fully standardized (a company may appear under slightly different name variants across trials), so sponsor-level counts are a reasonable approximation rather than an exact figure.
- The "white space" signal is a simple heuristic (recent trial count vs. distinct sponsor count), not a market-sizing model — it's meant to flag candidates for deeper qualitative research, not to be read as a conclusion on its own.
